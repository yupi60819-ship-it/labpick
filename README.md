# LabPick — 抗体・試薬 横断サーチ

created by Yuta Sogabe

実験で使う抗体・試薬を、内蔵カタログ、41 サイトの検索ランチャー、自分で登録した「マイ試薬」から探す静的 Web アプリです。素の HTML / CSS / JavaScript のみ。ビルド、npm パッケージ、外部 JavaScript、バックエンド、データ取得 API は使いません。

## 起動

`index.html` を直接開いてください。ローカルのデータファイルは通常の `<script>` で読み込むため、`file://` でも動作する構成です。全てのアセット参照は相対パスで、GitHub Pages のサブパスにも対応しています。ネット接続なしでも内蔵カタログと計算機を使えます。メーカーや文献の外部リンクには接続が必要です。


## 使い方

- **カタログ**：入力に応じて即時検索。空白区切りで AND 検索できます。例：`GAPDH CST`、`#4370`、`ab-8245`、`β actin`。全半角・大小文字・記号・ギリシャ文字の表記ゆれを吸収します。カタログ番号の完全一致を優先し、ヒット箇所を強調します。候補、人気キーワード、消去できる検索履歴もあります。
- **絞り込み**：カテゴリ、メーカー、用途、宿主、交差性、クローナリティ、標識、お気に入り、マイ試薬。それぞれに件数を表示します。選択中の条件はチップから個別解除できます。カード／表、4 通りの並び替え、24 件ずつの段階表示に対応します。
- **詳細**：製品名を押すと仕様、公式資料・CiteAb・文献・代理店のリンク、各種コピーを表示します。同じターゲットの他社製品を表示し、まとめて比較に追加できます。一次抗体・タグ抗体では、宿主に対応する内蔵二次抗体候補も表示します。
- **比較**：最大 4 製品を選択。2 件以上で下部の「比較する」が有効になります。異なる行をクリーム色で表示し、違いのみの表示、タブ区切りコピー、CSV 出力ができます。
- **お気に入り・購入リスト**：星ボタンでお気に入りに登録。「購入リストへ」で数量、見積単価（円）、メモを入力できます。未入力の価格は合計から除外し、0 円とは区別します。BOM 付き UTF-8 CSV、発注依頼文コピー、印刷用レイアウトに対応します。入力した見積単価の税込・税別をそのまま扱い、税は自動追加しません。
- **横断検索**：通常検索のキーワードを引き継ぎます。海外メーカー／国内メーカー／国内代理店／集約・文献サイトに分類。個別リンク、公式トップ、選択したサイトの一括オープンを使えます。複数タブがブロックされた場合はページの案内に従って個別に開くか、ポップアップを許可してください。
- **マイ試薬**：製品を追加／編集／削除できます。内蔵製品と同じ検索・比較・購入機能を使えます。削除すると、その製品へのお気に入り・購入・比較の参照も解除します。メーカーは定義済みリストから選択します。追加のメーカーが必要な場合は `data/makers.js` を編集してください。
- **データ管理**：右上の歯車からお気に入り・購入リスト・マイ試薬をまとめて JSON で保存／復元できます。取込は形式、型、id、メーカー、URL、参照関係、数値を検証し、件数を確認後に保存データ全体を置き換えます。不正なファイルの一部だけを読み込むことはありません。上限は 5 MB、マイ試薬 2,000 件です。検索履歴と比較選択は JSON バックアップに含みません。
- **ラボツール**：抗体希釈、C₁V₁=C₂V₂、必要質量の 3 計算機。液量・モル濃度の単位を選択できます。濃度の逆転、ゼロや負数、計算範囲外を検出します。
- **URL 共有**：検索語・フィルタ・並び順・表示形式・比較対象 id・開いている製品 id をハッシュに反映し、読み込み時に復元します。「共有」で現在の URL をコピーできます。ローカル保存の製品そのものや見積は共有 URL に含みません。別端末にはマイ試薬の JSON バックアップも必要です。`file://` の URL はローカルのパスなので、他の環境で閲覧するには公開済みページの URL を利用してください。
- **キーボード**：`/` でカタログ検索、`Esc` で詳細等のモーダルを閉じます。候補は上下矢印で選択できます。モーダルには見出し、native dialog、フォーカストラップを付けています。

## データの扱い

価格は内蔵していません。カタログ番号、宿主、クローンなどの製品同定を公式の商品ページやデータシートと照合できたものだけを採用しました。確認日：**2026-11-12**。確認元は [data/SOURCES.md](data/SOURCES.md) に記録しています。

- 仕様の空欄は **未収録** であり、用途非対応や交差性なしを意味しません。交差性・用途は確認できた一部のみを掲載しています。容量不明の製品に任意の容量を割り当てていません。
- CST 等は容量サフィックスなしの製品番号を使用する場合があります。包装別注文番号はメーカー公式ページで確認してください。CK04 も包装別番号ではなく Dojindo の製品コードです。
- 同じターゲットでも、抗原部位、アイソフォーム、交差反応、試料、使用法は同等とは限りません。交差性と用途の全ての組合せを保証するものではありません。一次・タグ抗体の66ターゲットで3社以上を収録し、β-Actin は 5 社、GAPDH は 4 社で比較できます。
- CST #7076 の宿主は **Horse**。Sigma G8795 は **IgM**。一般的な anti-Mouse IgG 二次抗体とは区別します。標識済み一次抗体や明示された非 IgG アイソタイプには IgG 用二次抗体を提案しません。アイソタイプ未収録の場合、候補は宿主に基づくものなので公式仕様の確認が必要です。
- 各外部サイトへのリンクは、最新情報や入手可能性を保証しません。公式資料にも改訂があります。注文前に番号・クローン・宿主・容量・適用条件を必ず確認してください。
- localStorage は全て try/catch 内で使用し、利用できない場合はメモリ上で動作します。その場合はページを閉じる前に JSON を保存してください。`file://` の保存範囲はブラウザの実装やファイルの場所に依存します。別 URL／別ブラウザ／プライベートモードでは保存データを引き継げない場合があります。

## データを追加する

1. 公式資料でメーカー、製品名、番号、抗体なら宿主・クローン・クローナリティを照合してください。確信できなければ追加しません。
2. `data/products.js` に `id`, `maker`, `name`, `catalog`, `category`, `target` を必須として追加します。`id` は重複しない小文字英数とハイフン。メーカー id は `data/makers.js` と一致させます。
3. 確認できるスペックだけを追加します。配列フィールドは `aliases`, `reactivity`, `applications`。日本語の別名は `aliases` に入れます。単クローン抗体では `host`, `clonality: 'Monoclonal'`, `clone` を記録します。価格フィールドは禁止です。
4. 確実なHTML商品ページは `url`、PDFのデータシート・説明書は `datasheetUrl`、同定に使った別資料は `verificationUrl` に設定できます。`datasheetUrl` は詳細モーダルに「データシート (PDF)」として別表示します。HTML商品ページを特定できない場合は `url` を省略し、メーカー検索にフォールバックします。3つのURLフィールドはいずれも認証情報のない http / https のみを許可し、`datasheetUrl` は `.pdf` のリンクを記録します。一般的な URL のパターンは製品ファイルへ書かず **メーカー定義だけ**を変更してください。
5. 商品リンクは「個別 `url` → メーカーの商品テンプレート → カタログ番号によるメーカー検索」の順に解決します。CST のテンプレートは番号から確実に指定できる公式データシートを使っています。Sigma の番号は URL 組立時だけ小文字化します。
6. メーカー追加時は定義の `id, name, country, type, homepage, searchUrl, color` を設定します。`productUrl` は番号だけから確実に作れる場合のみ設定してください。`searchVerified` / `productVerified` は検証状況です。新しい URL テンプレートは `data/makers.js` 内だけに記載してください。
7. 以下のチェックを実行し、確認元と更新日、下記件数表も更新してください。

## 計画との差分・指摘

1. REVIEW.md B対応で**52件から308件**へ拡充し、目標250〜350件の範囲に達しました。既存52件のidを維持し、確認できた公式仕様を補完。PLAN 2.3の一次・タグ抗体66ターゲットすべてを3社以上でそろえました。二次抗体・アイソタイプ・国内メーカー試薬・消耗品も追加し、価格は収録していません。
2. `assets/js/core.js` を追加し、検索・エスケープ・CSV・スキーマ・計算を共通化しました。通常の script 読み込みで、ES modules は使いません。検証用スクリプトと確認元索引・作業記録も追加しました。
3. 商品 URL を番号だけで確実に作れないメーカーは個別 URL または検索に限定しました。CST は公式データシートへリンクします。検索テンプレートは実ブラウザで確認し、未検証は 5 サイトのみです（上記）。
4. 二次抗体の提案は宿主だけでは不十分なため、明示された IgM 等と標識済み抗体を除外しました。宿主・IgG に加えて交差吸収、用途、試料種、標識を購入前に確認する必要があります。同じターゲットというだけで性能が同等とは判断しません。
5. `β ↔ b` のような正規化は計画どおり実装しましたが、短い単語では検索ノイズが増えます。カタログ番号やメーカーを併記すると絞り込めます。
6. URL 共有には個人カタログや見積そのものは含めません。別端末でマイ試薬を復元するには JSON も必要です。file:// の保存範囲と複数タブの許可はブラウザ次第なので、保存不可・コピー不可・ポップアップ遮断時の案内を追加しました。
7. 実ブラウザでの表示確認は実装後に別途実施しました（上記「実ブラウザでの確認」）。
